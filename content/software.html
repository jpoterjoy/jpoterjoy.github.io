Fortran · DART

Local particle filter

A localized particle filter for high-dimensional geophysical models, distributed with the open-source NSF NCAR Data Assimilation Research Testbed (DART). The latest version, with regularization and tempering, is on the LPF branch of our DART repository. Please cite Poterjoy (2016, 2022b).

CADRE-JEDI-Edu

Hands-on tutorials that introduce data assimilation methods in the Joint Effort for Data assimilation Integration (JEDI) using a two-layer quasi-geostrophic model. Developed through CADRE; our group contributed the local particle filter tutorial.
